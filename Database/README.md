# База данных «Читай, Пиши и не спиши» — инструкция

Папка содержит все артефакты по части «База данных».

## Состав папки

| Файл | Назначение |
|------|------------|
| `01_CreateDatabase.sql` | Полный скрипт создания схемы БД (таблицы, PK/FK, ограничения). |
| `02_Queries.sql` | 9 обязательных запросов (по одному, для скриншотов результата). |
| `csv/*.csv` | Тестовые данные для импорта через мастер SSMS (12 файлов). |
| `_verify_load.sql` | Вспомогательный скрипт (НЕ для отчёта): быстрая загрузка CSV через `BULK INSERT` для самопроверки. |
| `ReportTemplate.md` | Шаблон отчёта — заполнить и экспортировать в PDF. |

Имена таблиц/столбцов — в CamelCase, латиницей. Типы данных: `int`, `nvarchar`, `nvarchar(max)`, `bit`, `datetime`. Ограничения: `NOT NULL`, `UNIQUE`, `DEFAULT`, `CHECK` (рейтинг отзыва 1–10). БД в 3НФ.

---

## Шаг 1. Создание базы данных

1. Откройте **SSMS**, подключитесь к серверу.
2. В обозревателе объектов: ПКМ по `Databases` → **New Database…**, имя `ReadWriteDB`, OK.
   *(Либо раскомментируйте `CREATE DATABASE` в начале `01_CreateDatabase.sql`.)*
3. Откройте `01_CreateDatabase.sql`, выберите БД `ReadWriteDB` в выпадающем списке, нажмите **Execute (F5)**.
4. Убедитесь, что появились 12 таблиц в `ReadWriteDB → Tables`.

## Шаг 2. Импорт тестовых данных из CSV (мастер SSMS)

Импорт строго **в порядке зависимостей** (внешние ключи ссылаются на уже загруженные строки):

```
1. Roles            7. BookGenres
2. RequestStatuses  8. Reviews
3. ReadingStatuses  9. ReadingListItems
4. Users           10. Complaints
5. Genres          11. RoleRequests
6. Books           12. UnfreezeRequests
```

Для каждого файла:

1. ПКМ по `ReadWriteDB` → **Tasks → Import Flat File…** (или **Import Data…** — мастер SSIS).
2. Укажите путь к `.csv`, проверьте, что первая строка распознана как заголовки.
3. На шаге **Modify Columns**: задайте существующую таблицу-назначение (а не создание новой) и сопоставьте столбцы. Тип `Rating` — целое, даты — `datetime`.
4. Для таблиц с автоинкрементным ID (через мастер **Import Data…**) на странице сопоставления включите **«Enable identity insert»**, чтобы значения ID из CSV попали как есть и совпали с внешними ключами.
5. Запустите импорт, дождитесь «Success».

> Для отчёта обязательно сделайте скриншоты **минимум для двух таблиц**: окно мастера, сопоставление столбцов, результат («N rows transferred»).

**Кодировка:** все CSV — в UTF-8. Если кириллица отображается некорректно, на странице выбора файла укажите Code page **65001 (UTF-8)**.

> **Альтернатива для самопроверки** (не идёт в отчёт): можно загрузить все данные одним скриптом `_verify_load.sql` (он использует `BULK INSERT` с `KEEPIDENTITY`). Перед сдачей всё равно выполните импорт мастером и приложите скриншоты.

## Шаг 3. Выполнение запросов

Открывайте `02_Queries.sql`, выделяйте по одному запросу (между комментариями), жмите **F5**, делайте скриншот результата. Тексты запросов и скриншоты — в отчёт (раздел 7).

## Шаг 4. Резервное копирование и восстановление

**Бэкап:** ПКМ по `ReadWriteDB` → **Tasks → Back Up…** → Backup type: *Full* → укажите путь `.bak` → OK. Скриншот успешного завершения.

**Восстановление:** ПКМ по `Databases` → **Restore Database…** → Source: *Device* → выберите `.bak` → задайте имя (например, `ReadWriteDB_Restored`) → OK. Затем выполните проверочный запрос, например:

```sql
SELECT COUNT(*) AS UsersCount FROM ReadWriteDB_Restored.dbo.Users;
```

Скриншоты бэкапа, восстановления и проверки наличия данных — в отчёт (раздел 8).

## Шаг 5. Генерация полного скрипта (схема + данные)

1. ПКМ по `ReadWriteDB` → **Tasks → Generate Scripts…**
2. Выберите все объекты.
3. На странице **Set Scripting Options → Advanced**: параметр **Types of data to script = Schema and data**.
4. Сохраните в файл, например `ReadWriteDB_full.sql`.
5. Создайте новую БД (`ReadWriteDB_FromScript`), выполните в ней сохранённый скрипт, убедитесь, что таблицы и данные на месте. Скриншоты — в отчёт.

## Шаг 6. Экспорт данных в CSV и Excel

**Экспорт в CSV** (например, результат запроса №7):
- Выполните запрос → ПКМ по результату → **Save Results As…** → тип CSV. Либо **Tasks → Export Data…**.

**Экспорт в Excel** (самая объёмная таблица — `Reviews`):
- ПКМ по `ReadWriteDB` → **Tasks → Export Data…** → источник SQL Server, назначение **Microsoft Excel** → выберите таблицу `Reviews` → запустите.

Скриншоты процесса и содержимого полученных файлов — в отчёт (раздел 9). Сами файлы приложите к работе.

## Описание сущностей (для раздела «Предметная область»)

| Таблица | Назначение |
|---------|------------|
| `Roles` | Роли: Читатель, Автор, Администратор. |
| `RequestStatuses` | Статусы заявок и жалоб: На рассмотрении, Принято, Отклонено. |
| `ReadingStatuses` | Разделы списков чтения: Заброшено, В планах, Читаю, Прочитано. |
| `Users` | Пользователи: логин, пароль (хэш), email, отображаемое имя, роль, признак заморозки. |
| `Genres` | Жанры книг. |
| `Books` | Книги: название, описание, обложка, текст, автор, признак заморозки. |
| `BookGenres` | Связь «многие-ко-многим» книга↔жанр. |
| `Reviews` | Отзывы на книги с оценкой 1–10. |
| `ReadingListItems` | Книги в списках чтения пользователя (книга — в одном разделе). |
| `Complaints` | Жалобы на книгу / отзыв / пользователя с причиной и статусом. |
| `RoleRequests` | Заявки на получение роли (например, «Автор»). |
| `UnfreezeRequests` | Заявки на разморозку аккаунта или книги. |
